# 📤 GFG to X Poster - Chrome Extension

Easily tweet your solved [GeeksforGeeks](https://www.geeksforgeeks.org/) problems with one click!

## 💡 Features
- Manual day input
- Auto tweet text generation
- Works on GFG-160 challenge problems

## 🧩 How to Use
1. Clone or download this repo
2. Go to `chrome://extensions`
3. Enable **Developer Mode**
4. Click **Load unpacked** → select this folder
5. Visit a GFG problem page → Click "📤 Post to X" button
